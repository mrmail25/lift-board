# Evolution ladder spec (ladder v2, live)

Live since 2026-10-29 (ladder v2); stage bars follow Strength Level percentiles since the evening of 2026-10-29. Supersedes ladder v1 (2026-10-25), the allometric-curve bars and `data/evolution-levels-draft.md`; earlier proposals in `data/proposals/` are kept as history. Machine-readable rules: `data/evolution-rules.json` (generated by `tools/build_evolution.py` from `tools/evolution_rules.py` and `tools/evolution_sl.py`; never hand-edit). Reference implementation: `tools/evolution.py report(history, as_of)`. Parity reference: `data/evolution-reference.json`. Gap table: `data/proposals/swap3/sources.md`. Tests: `tools/test_evolution.py`.

**What this is.** A strength game ladder. Every number is a modelling choice [M] anchored on Strength Level's crowd data; estimated 1RM is a model, not a measured max. Nothing here is a health, fitness or medical measure. Source note shown in the app: "Stages follow Strength Level percentiles: the share of Strength Level users (self-logged lifts) a bar beats at your sex and bodyweight. Strength Level is not peer-reviewed, and some ranges are estimated from other published standards. The percentile line is an estimate. Estimated 1RM is a model, not a measured max."

## 1. Decisions
- Strength alone earns every rank, including Prime, Kong and Apex. The opt-in body-composition check unlocks ONLY the "Lean Prime" art and badge; it never affects rank.
- Optional sex setting; unset -> the men's table with the label "Using the men's table. Set sex in Settings to use the women's table."
- 3 of 5 core lifts promote; the barbell row may stand in for pull-ups and dips for bench (max one). Best-ever estimated 1RM. Never demote. Kong and Apex hide ("Locked stage") until reached. Plate badges are absolute loads (lb [135, 225, 315, 405, 495], kg [60, 100, 140, 180, 220]; the fifth plate hidden until earned).
- **Strength Level percentile ladder (Mr Dude via CoS, Oct 29 evening):** Each stage bar is a Strength Level (SL) population percentile at the lifter's bodyweight. SL's tiers beat 5 / 20 / 50 / 80 / 95% of its lifters (Beginner / Novice / Intermediate / Advanced / Elite). Stage entries: Knuckle-Dragger = the floor (start); Primate = beats 8% (top 92%; estimate: interpolated between Beginner and Novice); Neanderthal = Novice (20%); Prime = Intermediate (50%); Silverback = Advanced (80%); Kong = top 10% (estimate: interpolated between Advanced and Elite); Apex = beats 97% (top 3%; estimate: extrapolated above SL Elite). The Apex ceiling (Alpha Apex sits 2/3 of the way to it) = the 99th percentile, extrapolated (estimate). Chief and Alpha ranks sit at 1/3 and 2/3 of each stage gap. This replaced the plate-friendly anchor proposal (never shipped) and the published-bar alignment.
- **Bodyweight:** SL's per-bodyweight rows replace the allometric 0.67 curve; gaps beyond SL's rows are filled and flagged (section 5).
- **Display rounding:** every bar shown rounds to 5 lb / 2.5 kg with a monotonic guard, and ranking compares against the bar as shown (section 6).
- **Percentile line:** "Stronger than about X% of lifters your size" from the same curve; at or above the Apex bar "Top 3% of lifters your size" (section 7).

## 2. Stages, ranks and ids
Stages: Knuckle-Dragger -> Primate -> Neanderthal -> Prime -> Silverback -> Kong (hidden until reached) -> Apex (hidden until reached). Each stage has 3 tiers: `{stage}`, `Chief {stage}`, `Alpha {stage}` (21 ranks). Ids are language-neutral `<stage_id>.<tier>`, index = 3 x stage index + tier - 1 (0..20). Everyone starts at `knuckle_dragger.1`. `ladder_version` stays 2 (stage order and ids unchanged).

## 3. Values per lift
- **Core lifts:** bench press (`barbell-bench-press`), squat (`back-squat`), deadlift (`deadlift`), overhead press (`overhead-press`), pull-ups (`pull-up`). **Stand-ins:** barbell row (`barbell-row`), dips (`weighted-dip`).
- **Load lifts:** best-ever estimated 1RM (Epley load x (1 + reps/30), working sets with 1..12 reps, deload sessions and pr_exclude e1rm tags excluded), compared with the bars as shown at the set's day bodyweight in the display unit; best-ever = the set with the highest ladder position (rounding.position). report().lifts.<lift>.value = that estimated 1RM in the display unit; multiple = estimated 1RM / bodyweight (display only).
- **Rep lifts:** best-ever strict-rep value. A set with no added load counts its reps (any rep count). A weighted set (added load > 0, reps 1..12) converts to strict-rep equivalents [M]: E = (f x BW + added) x (1 + reps/30) is its estimated 1RM, and the strict reps that reach the same estimate at bodyweight alone are r_eq = 30 x (E / (f x BW) - 1), floored to a whole rep. f = exercises.json bodyweight_fraction (0.95), BW = bodyweight on the set's day (a weighted set without a bodyweight is not rated). Negative logged loads (assistance) are not counted. Same deload / tag exclusions (tags with reps_at_load in pr_exclude excluded for strict sets, e1rm for weighted sets). Compared with the whole-rep bars at the set's day bodyweight (a strict set with no bodyweight on file uses the anchor bodyweight bars: 180 lb men, 145 lb women).
  - Example: BW 180 lb, pull-up +45 lb x 5: E = (171 + 45) x 1.1667 = 252.0; r_eq = 30 x (252.0 / 171 - 1) = 14.2 -> 14 strict-rep equivalents. A model: Epley extrapolated to high reps is rough, so converted values are approximate. Labelled "Includes weighted sets (converted to strict reps, estimated)."
- **Bodyweight:** bodyweight for a set = the latest history.bodyweights entry dated on or before the set's session local date (startedAt || date); none -> settings.profile.bodyweight; none -> load lifts (and weighted rep sets) are not rated; strict reps use the anchor bodyweight bars. Unlike prs.py there is no backfill from a later entry: a later weigh-in never rewrites an older rank. Current bodyweight (targets): for next-rank targets: latest entry on or before as_of; none -> settings.profile.bodyweight; none -> no load targets (rep targets at the anchor bodyweight).

## 4. Strength Level curve
- **Stage minimums:** Each stage bar is a Strength Level (SL) population percentile at the lifter's bodyweight. SL's tiers beat 5 / 20 / 50 / 80 / 95% of its lifters (Beginner / Novice / Intermediate / Advanced / Elite). Stage entries: Knuckle-Dragger = the floor (start); Primate = beats 8% (top 92%; estimate: interpolated between Beginner and Novice); Neanderthal = Novice (20%); Prime = Intermediate (50%); Silverback = Advanced (80%); Kong = top 10% (estimate: interpolated between Advanced and Elite); Apex = beats 97% (top 3%; estimate: extrapolated above SL Elite). The Apex ceiling (Alpha Apex sits 2/3 of the way to it) = the 99th percentile, extrapolated (estimate). Chief and Alpha ranks sit at 1/3 and 2/3 of each stage gap.
- **Interpolation (chosen):** Percentile axis: linear between the tier points (5, 20, 50, 80, 95), i.e. value(p) = T_k + (p - p_k) / (p_(k+1) - p_k) x (T_(k+1) - T_k). Primate (8) = Beginner + 3/15 x (Novice - Beginner); Kong (90) = Advanced + 2/3 x (Elite - Advanced). Above 95 the Advanced -> Elite slope continues: Apex (97) = Elite + 2/15 x (Elite - Advanced); ceiling (99) = Elite + 4/15 x (Elite - Advanced), so the ceiling always sits above Apex. Chosen because SL publishes only the five tier points and linear is the simplest rule that hits every published point exactly; it is an estimate between them.
- **Estimates:** Primate: beats 8% (top 92%): interpolated between SL Beginner (5%) and Novice (20%): Beginner + 3/15 x (Novice - Beginner). Kong: top 10%: interpolated between SL Advanced (80%) and Elite (95%). Ceiling: 99th percentile: SL publishes nothing above Elite; the Advanced -> Elite slope is extended (cross-check: men at 180 lb, bench ceiling 355.5 lb is below Symmetric Strength "Elite" 380 lb).
- **Knuckle-Dragger (floor):** the progression model's first-month start, carried across bodyweights as a fixed fraction of SL Beginner (`curve.tables.<sex>.<lift>.kd_fraction`; men bench 0.566929, women bench 0.78962); 0 reps for pull-ups and dips.
- **Rank bars:** bars at bodyweight BW: stage entries from curve (percentiles on SL's tiers at BW); tier 1 = stage entry; Chief = entry + 1/3 x (next entry - entry); Alpha = + 2/3; the Apex gap runs to the 99th-percentile ceiling. Then rounding (nearest 5 lb / 2.5 kg for loads with the monotonic guard; whole reps, rounded up, for pull-ups and dips).
- **Pull-ups:** SL publishes pull-up reps by bodyweight for men and women (https://strengthlevel.com/strength-standards/pull-ups/lb); used directly. SL lists some low rep tiers as "< 1" rep, stored as 0 (`lt1_cells`): women's pull-up Beginner and Novice at every bodyweight, women's dip Beginner (and Novice at some bodyweights), men's pull-up Beginner at most bodyweights and men's dip Beginner at 110-120 lb. So a woman's pull-up bars up to Neanderthal are 0 and any logged strict rep meets them. No lift or sex is missing from SL.

## 5. Bodyweight, clamp and gap fill
- Bars follow SL's per-bodyweight rows directly (10 lb steps), linear between the two rows around the lifter's bodyweight (in lb; kg bodyweights x 2.20462). This replaces the allometric 0.67 curve. Each lift and sex uses its own SL rows, so the bodyweight effect is SL's own (e.g. men's Intermediate bench 1.36x at 130 lb, 1.22x at 180 lb, 1.14x at 300 lb).
- **Clamp:** Rows run beyond SL's range to physical bounds (men 100-400 lb, women 80-330 lb), using filled rows (gap_fill). Outside the bounds: below the low bound a load lift keeps the low-bound row's multiple (tier x BW / bound) and a rep lift keeps its reps; above the high bound the high-bound row is held (same loads and reps). So a lighter lifter is never asked for a higher multiple than at the bound, and a heavier lifter is never asked for more load.
- **Gap fill:** Where SL has no row (men below 110 lb or above 310 lb, women below 90 lb or above 260 lb), rows are filled every 10 lb up to the bounds and flagged in tables.<sex>.<lift>.row_meta (source, estimated: true, method). Barbell lifts: ratio-matched to SL at the overlap: SL's edge row x (BW / edge BW)^b, with b = the OpenPowerlifting bodyweight trend for that lift and sex (weighted log-log slope of the median raw full-power best lift per 10 lb bodyweight bin, fitted over the window next to the edge). OHP and barbell row borrow the bench slope (OpenPowerlifting has no press or row). Pull-ups and dips: no other published rep standard by bodyweight exists, so SL's own trend is extended (linear fit to its 5 rows nearest the edge, per tier), floored at 1 rep where SL's edge row is >= 1 (else 0). SL publishes every lift for both sexes, so no lift or sex is missing; the only gaps are bodyweight ranges and the ceiling above Elite.
- Filled rows: men 100 lb and 320-400 lb, women 80 lb and 270-330 lb, for all seven lifts (`row_meta` flags each one). Full gap table with sources, access dates and methods: `data/proposals/swap3/sources.md`. Not shown in the app.
- **Sources (none peer-reviewed):** Strength Level standards pages (https://strengthlevel.com/strength-standards/bench-press/lb, https://strengthlevel.com/strength-standards/squat/lb, https://strengthlevel.com/strength-standards/deadlift/lb, https://strengthlevel.com/strength-standards/shoulder-press/lb, https://strengthlevel.com/strength-standards/pull-ups/lb, https://strengthlevel.com/strength-standards/bent-over-row/lb, https://strengthlevel.com/strength-standards/dips/lb), accessed 2026-10-29; OpenPowerlifting bulk CSV (https://openpowerlifting.gitlab.io/opl-csv/, data date 2026-10-24) for the bodyweight trend only.

## 6. Display rounding and ranking
- **Formula:** bar(unit) = step x floor(raw / step + 0.5 + 1e-4), raw = the curve bar (lb) at the bodyweight, converted to the display unit (settings.unit; kg = lb / 2.20462). Nearest step; an exact half rounds up (the 1e-4 slack absorbs float noise). JS: step * Math.floor(raw / step + 0.5 + 1e-4).
- **Applies to:** every barbell-load bar (bench, squat, deadlift, OHP and the barbell-row stand-in), at every rank and every bodyweight. Rep bars (pull-ups, dips) are whole reps: ceil(raw - 1e-9).
- **Guard:** monotonic guard, per lift, sex table, unit and bodyweight: walk the 21 rank bars and the ceiling in order; a rounded load bar <= the one before it is raised to the one before + one step, so load bars strictly increase (the guard only ever raises). Rep bars never fall below the bar before; they may be equal where Strength Level publishes "< 1" rep (stored as 0), e.g. the women's pull-up bars below Prime. Largest guard raise over bodyweights in 5 lb steps (lb): men bench +10 lb at 100 lb (ceiling); men squat +10 lb at 100 lb (ceiling); men deadlift +5 lb at 100 lb (ceiling); men ohp +15 lb at 100 lb (ceiling); men row +10 lb at 105 lb (ceiling); women bench +10 lb at 80 lb (Alpha Apex); women squat +10 lb at 80 lb (ceiling); women deadlift +10 lb at 80 lb (ceiling); women ohp +20 lb at 80 lb (ceiling); women row +10 lb at 80 lb (ceiling).
- **Ranking:** Ranking compares against the bars as shown in the lifter's own display unit: a set meets a rank when its estimated 1RM in the display unit (or its strict reps) >= that rank's bar at the set's day bodyweight (1e-6 slack). A lifter who hits the number shown always gets the rank. lb and kg bars can differ by rounding, so switching units can move a boundary by up to one step.
- **Position:** ladder position of a set: i + clamp((x - bar_i) / (bar_(i+1) - bar_i), 0, 1) with i = the highest rank whose bar the set meets (bar_21 = the ceiling; at or above it the position is 21); below the first bar: (x - bar_0) / (bar_1 - bar_0) (< 0, still Knuckle-Dragger). A lift's best-ever set = the highest position (ties: the higher value, then the earlier set). Lift rank = min(20, max(0, floor(position))); per-lift progress at shown rank s = clamp(position - s, 0, 1).
- **Why:** Bars on screen are loadable round numbers (5 lb / 2.5 kg), and the number shown is exactly what earns the rank.

## 7. Percentile line
- Per lift: from the lift's best ladder position on the same curve as the bars: positions 3, 6, 9, 12, 15, 18 (Primate ... Apex entries) read 8, 20, 50, 80, 90, 97%, the ceiling (21) 99%, linear in between (the Chief and Alpha thirds and SL's linear tiers make this the SL percentile of the shown bars). Below Primate: from SL's Beginner (5%) and Novice (20%) lines at the set's bodyweight, capped at 7.9% (just under Primate); below Beginner: band under_5 (no number). Top rule: at or above the Apex bar (position >= 18) the band is top, shown as "top 3%" (labels.percentile_line_top with {top} = 100 - curve.stage_pct.apex = 3); pct still records the curve value (97-99) for analytics.
- overall = the slot at the 3rd-highest position among the 5 slots after substitution (the promotion rule); fewer than 3 rated slots -> none. Exactly at the Prime bars reads 50%.
- Card: Card line: band estimate -> labels.percentile_line with {pct} = floor(percent); band top -> labels.percentile_line_top with {top} = 100 - curve.stage_pct.apex; under_5 or no overall -> no line. Per-lift values in report().percentile.lifts. Lines: "Stronger than about {pct}% of lifters your size"; top: "Top {top}% of lifters your size".
- An estimate relative to Strength Level's own user base (self-logged lifts), not peer-reviewed; a model, not a measurement. Follows the computed rank (a held award does not change it).

## 8. Promotion, progress, targets, hidden stages
- overall rank = the highest rank index met by at least 3 of the 5 core lifts (after at most one stand-in substitution). A lift meets a rank when its best ladder position >= that rank's index, i.e. its estimated 1RM (or reps) reached the bar as shown at that set's bodyweight. Unlogged or unrated lifts meet nothing. Everyone starts at knuckle_dragger.1.
- **Per-lift stage:** each lift (core and stand-ins) shows its own rank: the highest rank whose threshold it meets (hidden stages beyond the revealed ladder show as "Locked stage").
- **Never demote:** shown rank = max(computed rank, history.evolution.awarded). The app stores the highest rank shown in history.evolution.awarded {stage, tier, ladder_version: 2}; a drop, a bodyweight gain, a sex change or a deleted set never lowers it (held: true while computed < awarded).
- **Progress:** p = clamp(position - s, 0, 1), with position the lift's best ladder position (rounding.position) and s the shown overall rank; unlogged / unrated -> 0. 3rd-highest of the 5 slot progresses (core lifts after substitution). It reaches 1.0 exactly when a 3rd lift meets the next rank, which is the promotion rule. At the top rank (apex.3) progress is null. Display: pct = floor(100 x overall).
- **Targets:** for each slot: the next rank's bar as shown at the current bodyweight in the display unit (load lifts: an estimated 1RM on the 5 lb / 2.5 kg grid; rep lifts: whole reps). Reaching exactly that number earns the rank on that lift. No current bodyweight -> no load target (reps use the anchor bodyweight).
- **Hidden stages:** kong and apex stages (only these two; silverback is visible) show as "Locked stage" in the ladder, the next-rank name and per-lift stages until the overall rank (with the awarded floor) reaches them. When the shown rank first enters Kong (or Apex), `newly_revealed` lists it once.

## 9. Substitution (max 1)
- Barbell row for pull-ups: barbell row estimated 1RM vs curve.tables.<sex>.row (SL bent-over row percentiles); Strength Level bent-over row standards by bodyweight (men and women).
- Dips for bench press: strict dip reps vs curve.tables.<sex>.dips (SL dips percentiles); Strength Level dips standards by bodyweight (men and women).
- Rule: only when a core lift is not trained (no qualifying working set ever, deload excluded) and its stand-in has a rated value. At most one substitution; if two are possible, take the one giving the higher overall rank, then higher overall progress, then the order above. A trained-but-unrated core lift (e.g. no bodyweight) is not substituted. Label: "{stand_in} stands in for {lift}".

## 10. Plate badges (separate from rank)
Unit: settings.unit ("lb" default | "kg") picks the set; both lists exist. lb [135, 225, 315, 405, 495], kg [60, 100, 140, 180, 220]. Bench, squat, deadlift: 5 badges; overhead press: 2. earned by the first done working set (non-deload, reps >= 1, not tagged with weight in pr_exclude) whose logged load, converted to the setting unit, is >= the plate load - 0.01. A real set, not an estimate. Independent of rank.
- **Hidden five plates:** The five-plate badges (495 lb / 220 kg: five 45 lb or 20 kg plates a side on a 45 lb / 20 kg bar) on bench, squat and deadlift are hidden until earned. Only these entries carry a hidden key: hidden: true and label "Hidden badge" until a qualifying set exists, then hidden: false and the normal label, shown like the other plate badges. Plates 1-4 have no hidden key. Overhead press stays at two plates. Not a tier; independent of rank. Unearned entry: `{"id": "bench.plates5", "lift": "bench", "plates": 5, "load": 495, "unit": "lb", "label": "Hidden badge", "earned": false, "date": null, "set_id": null, "hidden": true}`; once earned: the normal label, earned true, date and set_id set, hidden false.

## 11. Lean Prime (opt-in, art and badge only)
- Opt-in physique condition that unlocks ONLY the "Lean Prime" art and badge. It never affects rank. A leanness game condition, not a health measure. Badge: unlocked when lean.status == pass and the shown rank is at stage prime or above; stale -> shown greyed (prime is stage 3 in ladder v2, so silverback, kong and apex also qualify).
- Opt-in: settings.bodyComp.optIn === true. Never on by default; never asked during onboarding. Hide switch: settings.bodyComp.hidden === true hides every body-composition field, status and badge (status "hidden"). Age: settings.profile.birthDate (YYYY-MM-DD) gives age at as_of; under 18 -> no body-composition features at all (status "unavailable"). Age unknown -> not offered until a birth date is entered (status "needs_age" when opted in).
- Primary: Waist-to-height ratio men <= 0.46, women <= 0.45; fallback Entered body-fat % men <= 15%, women <= 23% (dexa, calipers, bia). Age allowance [M] not evidence-based; a game allowance. use the best (lowest) reading of the decisive method dated within the last 90 days up to as_of, so the mark does not flicker; only older readings -> stale (greyed).
- Copy rules: Use "lean" and "visible physique". Never "healthy", "fit" or "ideal"; no "lose X" prompts; no streaks, notifications or comparisons tied to waist or weight.
- Waist-to-height ratio as a height-adjusted waist measure: Ashwell M, Gunn P, Gibson S. Obes Rev. 2012;13(3):275-286, doi:10.1111/j.1467-789X.2011.00952.x (verified via Crossref; cited only for where the measure comes from). Cut-offs are game cut-offs [M].

## 14. Migration of v1 awards (history.evolution.awarded)
- **Detect:** history.evolution.awarded without ladder_version (or ladder_version 1) is a v1 award. Accepted v1 forms: {stage, tier} (stage id + tier, the documented form), {index} or a bare integer (a v1 rank index 0..20).
- **Rule:** For a stored v1 award at v1 index i (0..20; old stage order, old flat tables for the user's current sex table), at this lifter's current bodyweight (no bodyweight -> the anchor bodyweight, 180 lb men, 145 lb women): (1) t = 3 of 5: the HIGHEST v2 rank where at least 3 of the 5 core slots have a v2 bar <= the v1 rank's bar for that lift x (1 + tolerance) (load lifts: the v2 curve bar, unrounded lb, vs the v1 multiple x bodyweight x 1.03; pull-ups and dips: the whole-rep v2 bar vs the v1 reps x 1.03); a failing core slot may count through its stand-in (barbell row for pull-ups, dips for bench press) when the stand-in passes, at most one substitution. (2) p = i: the same step number on the v2 ladder. (3) q = the previous floor: the HIGHEST v2 rank whose bars on all 5 core lifts are each <= the v1 bars x (1 + tolerance). (4) floor = max(t, p, q). (5) Hidden cap: a migration never unlocks a hidden stage on its own: if floor >= the first Kong index (15) and t < 15, the floor is capped at Alpha Silverback (14); likewise, if floor >= the first Apex index (18) and t < 18, it is capped at Alpha Kong (17). Only a real 3-of-5 result can place a migrated award in Kong or Apex. tolerance = 0.03. All of this applies ONLY to migrating a stored v1 award; computed ranks never use it. Then shown = max(computed v2 rank, floor); awarded_out is written back with ladder_version 2 and never lowered again.
- **Tolerance:** `migration.tolerance` = 0.03. Migration only; computed ranks never use it.
- **Labels:** The floor is at least the same step number as the v1 award (a v1 Prime, step 12, lands at least at Silverback, step 12, in v2) and never below the previous floor, except that a migration alone never reaches Kong or Apex; see migration.table. The computed rank from the user's logged lifts can land higher; nothing the user lifted is lost. migration.table is computed at the anchor bodyweight (180 lb men, 145 lb women) with the 3% tolerance: three_of_five_index = t, same_step_index = p, previous_floor_index = q, hidden_cap = true when step (5) lowered the floor (to Alpha Silverback or Alpha Kong); no_tolerance_floor_index = the full rule without the tolerance. The app computes the floor at the lifter's current bodyweight.
- **Output:** report().awarded_migration = {from: v1 id, from_index, to: v2 id, to_index} when a v1 award was read, else null.

## 15. Effort check (progression model, estimates)
