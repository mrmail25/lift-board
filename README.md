# Lift Board

A magnetic-whiteboard style weekly bodybuilding planner with a live volume panel and body heatmap. Workouts are saved locally in your browser.

Body map: [MuscleMap](https://github.com/Jsplice/MuscleMap) (@musclemap/assets 1.1.0), MIT License, © 2026 Jsplice / MuscleMap contributors (see `img/mm/LICENSE-MuscleMap.txt`). Body photos are AI-generated.
